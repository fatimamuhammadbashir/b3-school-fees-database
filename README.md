# B3 School Fees Management Database

## Project Overview
This project is a school fees management database built using SQLite.

## Objectives
- Manage student records.
- Manage school fee types.
- Create student invoices.
- Record payments.
- Track discounts.
- Calculate outstanding balances.

## Technologies
- SQLite
- SQL
- Python

## Database Tables
1. Students
2. Fee Types
3. Invoices
4. Discounts
5. Payments

## Project Features
- Primary and foreign keys.
- SQL JOIN operations.
- GROUP BY and aggregate functions.
- Payment tracking.
- Outstanding balance reports.
